Ações de Sincronização

Como funciona: O sistema opera 100% offline (banco de dados local em arquivo H2). Todas as vendas, produtos e clientes são registrados localmente. Quando há conexão com o servidor central (configurado em application.properties), os dados são enviados automaticamente a cada 60 segundos. O estoque é atualizado tanto localmente quanto após a sincronização com o servidor.
